Hutan Kota Lempung

Tentang Kami

Hutan Kota Balas Klumprik Surabaya adalah destinasi alam yang menyediakan berbagai fasilitas menarik, termasuk area pembibitan buah, camping ground, sepeda air, dan playground. Tempat ini menawarkan pengalaman edukatif dan rekreasi untuk semua kalangan.

Di sini, pengunjung dapat belajar tentang proses pembibitan berbagai jenis buah, menikmati suasana alam dengan berkemah di camping ground, serta bersantai sambil bermain di playground atau mengelilingi danau dengan sepeda air. Hutan kota ini menjadi pilihan tepat untuk rekreasi sekaligus edukasi di tengah kota Surabaya.

Camping

Camping adalah kegiatan rekreasi yang melibatkan menginap di alam terbuka, seringkali di area perkemahan atau tempat yang ditunjuk. Aktivitas camping populer di antara banyak orang, karena ini adalah kesempatan untuk bersantai, menjelajahi alam, dan menjauh dari rutinitas sehari-hari.

Hutan Kota Langsa menyediakan fasilitas untuk melakukan aktivitas camping, anda dapat mendirikan tenda tempat Anda akan tinggal selama berada di luar ruangan. Anda dapat membuat api unggun dan memasak di atas api unggun atau menggunakan peralatan memasak portabel seperti kompor camping. Nikmati hidangan sederhana seperti sosis panggang, jagung bakar, atau masakan kreatif lainnya di bawah langit terbuka.

Malam hari adalah saat yang sempurna untuk berkumpul di sekitar api unggun. Anda dapat membakar kayu, menyanyikan lagu, bermain gitar, dan bercerita. Jangan lupa untuk memadamkan api dengan benar sebelum pergi tidur atau meninggalkan area api unggun.

Camping bisa menjadi kesempatan untuk bermain permainan kelompok seperti bola voli, bola pantai, atau permainan papan. Ini adalah cara yang bagus untuk bersenang-senang bersama teman dan keluarga Anda di alam terbuka.
